# GroupCart initial release

- Multi-seller browsing, tag search and role-specific navigation.
- Atomic checkout split into seller orders under one checkout group.
- Per-seller fulfillment state and customer receipt/cancellation flows.
- Correct remaining-item totals and safe failed-checkout cart behavior.
- Portable original MySQL sample schema and configuration template.
- Unified frontend/backend startup, disabled debug mode and removal of login-payload logging.

This package contains no local MySQL server, connection passwords, IDE environment, Git history or project backups. The existing running development installation is unchanged.
